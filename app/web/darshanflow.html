🌿 Multi-Platform API & Channel Connector (FB · IG · YouTube · Telegram)

1. Facebook Page Kaise Connect Karein (17-Photo Mixed Post)

• Facebook Page ID: Apne Facebook Page ke About → Page Transparency mein jaayein aur Page ID copy karke neeche daalein.
• Page Access Token: developers.facebook.com → Tools → Graph API Explorer kholein, apna App select karein, User or Page mein apna Page chunein, permissions mein pages_manage_posts, pages_read_engagement add karein aur Generate Access Token karke paste karein.

2. Instagram Professional Account Kaise Connect Karein (Post 1: 1→7 & Post 2: 1→10)

• Apne Instagram account ko Professional/Creator banakar apne Facebook Page se link karein.
• Graph API Explorer mein instagram_basic aur instagram_content_publish permission lein, phir me?fields=instagram_business_account run karke apna 17-digit Instagram Business ID copy karein.
• Instagram API ko photos upload karne ke liye public image link chahiye hota hai—iske liye api.imgbb.com se free ImgBB API Key lein aur neeche daalein. App khud 4:3 crop karke dono Carousels (7 Portrait + 10 Landscape) Instagram par post kar dega!

3. YouTube Community Post Kaise Connect Karein

• Google ke official YouTube API mein keval Video upload hota hai, multi-photo Community Post ka direct public API nahi hota.
• Isliye humne 2 tareeke diye hain: (A) Apna YouTube Channel Handle (jaise @MyDarshanChannel) daalein aur "YOUTUBE STUDIO 1-CLICK ASSIST" dabayein—yeh apne-aap Caption copy karega, 4:3 sequenced photos download karega aur seedha aapka YouTube Community Post box khol dega! (B) Agar aap Make.com / n8n Webhook use karte hain, toh Webhook URL daalein.

4. Telegram Channel Kaise Connect Karein

• Telegram par @BotFather ko /newbot bhejkar Bot Token lein, apne Bot ko Channel mein Admin banayein, aur Channel username (jaise @my_darshan) daalein.
