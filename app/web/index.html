    Control from your phone.

    Keep your livestream PC on and connect your phone to the same trusted Wi-Fi.

    1. In the Windows launcher, click Enable mobile access.
    2. Open the phone address shown there in Chrome or Safari.
    3. Enter the launcher’s pairing code. Bookmark the page for easy access.

    Mobile control is for your local network. This version uses HTTP; use a trusted private Wi-Fi and do not expose the port to the internet. Closing the browser is fine; closing the Windows app stops future automation.

    ON YOUR WINDOWS DESKTOP

    See the real browser actions.

    Record and review your own YouTube, Facebook and camera workflows once. Visible mode replays real browser clicks and text entry. OBS remains visible and is controlled through WebSocket. Login, UAC and security prompts stay manual.

    Keep Windows unlocked. Recording your manual actions can create public broadcasts or move the camera. This is a calibrated workflow tool, not a preconfigured robot for every website. Test it under supervision.

    Automation mode

    Applies after saving. Visible mode needs reviewed workflows before you enable automation.

    Chrome connection

    How to connect your existing Chrome

    Keep your logged-in Chrome window open. Enable “Allow remote debugging” at chrome://inspect/#remote-debugging, save “My running Chrome”, then Connect my Chrome. Accept Chrome's permission prompt for this connection. After restarting Chrome or Live Desk, connect again locally. You can revoke access on that Chrome settings page.

    One-time workflow recording

    My running Chrome opens a managed site tab in your existing browser and uses its current login; it never launches a replacement browser. Separate Live Desk browser uses its own persistent sign-in profile. Site sessions can still expire, and the correct account must be selected. Finish login before recording. Ordinary text-field values are never captured: map each field after recording.

    Review targets and text fields

    Select the account/Page name element you recorded as the identity check. It must be visible on the entry page before clicks. Remove any exploratory or unwanted clicks. Input fields must use a run variable, never a password or fixed date.

    Change a recorded click to “Check result” for a visible confirmation. Camera workflows must end with a result check. Date uses YYYY-MM-DD and time uses HH:MM; only map compatible text inputs. Embedded/legacy camera plugins, file uploads, dropdown selections and security prompts are not replayed automatically.

    Watch progress here. Record and configure workflows on the Windows PC.

    Run history and recovery

    Pause automation before inspecting a run. Inspection reads OBS and the exact recorded platform events. It never starts, ends or deletes a broadcast.

    Mark reviewed only after you have checked both platforms and the camera. This cancels remaining actions for that recorded run; drafts and the full journal are kept. It does not stop a patrol or end a live.

    Settings backup

    Save program timings, destinations and OBS profile names. Passwords, tokens, browser sessions, executable paths and network addresses stay on this PC. Visible workflows and run history are not part of this portable backup.
