LIVE DESK SOCIAL MEDIA — OPERATOR GUIDE

Social posting uses API adapters with visible progress in Posting queue.
The browser-click recipes in Visible automation currently cover live-stream
workflows, not the new social posting adapters.

1. Accounts
Facebook Page and YouTube use the existing Connections settings and Windows
Credential Manager. Open Social Media > Accounts > Check posting accounts.
For Instagram, link a Business/Creator professional account to that Page,
grant instagram_basic + instagram_content_publish and pages_read_engagement
with the relevant Page access. Use detected Instagram account, then Save.
Page posting needs pages_manage_posts. Account reads do not prove publishing
permissions. New/unaudited YouTube API projects can be restricted to private
uploads; the app checks returned visibility and retains the video ID if it
was not applied. Existing youtube.force-ssl authorization supports uploads.

2. Import and edit
Upload up to 25 JPG, PNG or MP4/MOV files per batch. File limit: 1 GB; saved
library limit: 5 GB. Export camera RAW files as JPG first. Photo crop, position,
brightness, contrast, colour and optional text watermark are previewed locally. Save edited copy makes
an immutable JPG, with its longest side up to 1440px, preserving the original.
A Facebook-only post can use 17 photos; other photo posts can use 10.
One video or Facebook-only text is also supported.
YouTube Community photos use manual handoff. Automatic YouTube API posting uploads a
video; it does not create a live broadcast or replace a stream key.

3. Draft, preview and approve
Choose destinations, exact media, title, caption, IST posting time, YouTube
visibility and audience. Save draft, then Preview & approve. Editing a
cancelled/unused draft makes a new revision and clears previous approval.
Another device cannot approve an old preview or silently overwrite a newer
draft. Approval by itself does not enable posting. The Social Media switch
is separate from the live automation switch.

4. Enable posting
Only approved queued posts run. Keep Windows awake and the host running.
Posting waits for active OBS outputs, connection operations and the live
preparation/start window. A post over 15 minutes late is held for review.
Pause posting prevents future jobs. A network request already sent may finish.
Pause Social Media before installing an update. Quit Live Desk also stops
future social posts. Closing only the dashboard leaves the host running.

5. Instagram media
For API posting, photos must be JPG, under 8 MB, 320–1440px wide, and
between 4:5 and 1.91:1 (square works). The PPT 3:4 portrait format is
preserved in a manual photo package; it is not silently cropped to 4:5.
For local JPGs the adapter creates unpublished Page photos and asks Instagram
to fetch their Meta-hosted URLs. Their IDs are retained in the local receipt.
This hosting path needs a supervised account test because fetch availability
can depend on Page/media permissions. Uploaded PNGs can be edited as JPG.
For a Reel, host the SAME video at a publicly fetchable HTTPS URL and save
that address in Media library. Private PC/LAN addresses cannot be used. Hosting
that video is a separate setup; this app does not expose local files publicly.

6. Failures and existing post verification
A receipt is saved before each platform write. A request timeout or restart
holds the item for review and does not automatically repeat it. Posting pauses
after a write failure. Successful destinations retain their IDs and links.
If the post already exists, enter its platform post ID and Verify existing
post. The adapter only reads it and checks account ownership (and YouTube
visibility). Instagram lookup is bounded to the latest 100 account posts.
If it is absent, inspect every unresolved destination, then Create corrected
draft. Successful destinations are excluded. Review and approve it separately.
Never create a replacement without first checking whether the uncertain post
was actually published.

7. Mobile and WhatsApp
A paired Wi-Fi operator can prepare and approve posts. Viewer devices receive
status only; unpublished captions and local media are restricted to operators. Account setup remains
local to the Windows PC. The existing internet relay's live controls are not a
media uploader or social composer in this release. In Posting queue, Share
link opens the mobile share sheet or copies text for WhatsApp. No WhatsApp
Group, Community or Channel message is automatically sent. The intended
WhatsApp destination must be specified before adding that integration.

8. Three photo columns (0.10.5)
Social Media > Darshan batch now has three independent uploads:
- 7 portrait photos (3:4), used in the same order for Instagram and YouTube.
- 10 landscape photos (4:3), used in the same order for Instagram and YouTube.
- 17 Facebook photos, in a separately selected order; mixed ratios are allowed.

Upload each column, then use arrows, the position selector or drag within that
column. Photo 1 is the cover. Moving a Facebook photo does not change either
Instagram/YouTube group. Import order is the file order supplied by the browser;
always check the numbered preview. There is no reference matching or inferred
subject order. Repeated copies of the same file in one column are skipped.
The same original may be reused across different columns.

Upload fills empty positions. If the selection exceeds the remaining positions,
the app asks before replacing that column. Clear column removes selections;
Remove removes one position and shifts following photos up. Neither action
deletes originals or already-created drafts. Edit copy is optional and creates
a separate JPG only when explicitly saved. Imports preserve the original bytes.
Desktop shows three columns side-by-side; narrow screens stack them, with a
scrollable photo area per column. Counts, order and first-photo covers stay visible.

Set the shared caption and three IST times, then Review & create five drafts.
Save progress keeps incomplete columns for later. All positions must be filled
with distinct photos within each column before creating drafts. Format warnings
are displayed on affected photos. Current Instagram landscape API requirements
remain JPG under 8 MB, width 320–1440; images are never silently resized.
Repeated creation of the same saved batch reuses its five existing drafts.
Changing a batch leaves previous drafts unchanged: review old drafts before
approving replacements. Older saved batches migrate their existing Facebook
order and media references without deleting anything or rebuilding posts.

Facebook and Instagram landscape drafts use the existing approved API queue.
Instagram portrait and both YouTube Community drafts use manual photo handoff.
Preview & approve freezes a manual package as Ready · manual upload. It does
not queue an API request. Download ordered photos creates a ZIP with numeric
filenames (01 is the cover), caption.txt and order.json. Download never posts
or schedules. Open the platform in your browser, verify the account, upload
photos in number order, paste caption and set that platform's time yourself.
YouTube supports up to 10 images per Community post. The feed may display a
square preview; opening a photo shows the full image. The package retains
3:4 / 4:3 as requested. Mark completed only after checking the actual post.
Completed by operator is your confirmation, not an API-verified receipt.
The official YouTube Data API reference has no Community create-post method.
This release does not add browser-click automation for photo posting.
Manual packages are available to authenticated PC/Wi-Fi operators; viewer
roles cannot download the package or see batch assignments/caption.

9. Delete several library photos together
Social Media > Media library > Select all photos (or tick individual files) >
Delete selected. Review the exact filenames. Cancel keeps every file intact.
Select all photos selects images; individual deletion selections can also
include videos. Up to 500 files can be reviewed/deleted per operation.
By default, batch assignments and all draft/post references are retained.
Optional: tick Also remove unused drafts and clear batch slots for these photos.
The confirmation lists the unused draft titles and batch slot numbers that will
be removed, in addition to filenames. Approved/queued, posting, posted, review,
manual-ready and manually-completed records always protect their media.
The app rechecks the selection and references when confirming; changed plans
need a new review. Busy local files are retained, with a count in the result.
Photos are staged for local deletion before committing metadata. Interrupted
moves are restored on restart if still referenced in saved state, or cleaned
up if the removal was already committed. Original imported PC files and live
settings/credentials stay intact. No platform post is deleted or sent.

No user tokens, passwords, stream keys or local media are included in releases.
This pilot uses isolated fake accounts for automated tests. Actual posting and
platform permission/audit checks require a supervised operator account test.

10. Previous reference matching
The 0.10.3/0.10.4 reference-import and automatic matching controls are no longer
loaded by the daily photo screen. Saved references are not used in the three
column workflow. Your explicit order is authoritative. No AI training, matching
or automatic cross-column selection runs when importing photos.
