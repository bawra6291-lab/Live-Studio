# Live Desk 0.10.6

Take control of an already-running YouTube and Facebook live with the configured existing Official stream and OBS outputs.

When live/recording are idle, pause live automation and Social Media posting before installing. Saved settings and credentials stay in place.

1. Save the intended program's camera actions and optional Live end time in Schedule.
2. After manually starting both platforms, pause automation, then open Overview > Control running live.
3. Select the program and its start date in IST. Choose Inspect running live. Inspection is read-only.
4. Review both event titles, links, remaining camera steps and end time. Select Take control & enable, then confirm.

Confirmation reads both platforms and OBS again. It refuses changed events, unknown or restarted outputs, mismatched stream keys, missing start times, duplicate ownership and expired previews. No broadcast is created, bound, started or restarted by takeover. The 90-second preview contains no stream keys or credentials.

Only this existing live is managed in this session. After-BOTH-live delays use the actual verified platform start times. Past steps are skipped; remaining steps run once. A blank end time keeps manual ending. Pause automation stops future camera/end actions.

A previously verified-started run resumes through Enable automation. A partial preparation can attach only when its saved event IDs and plan match the live. The original diagnosis is retained in the audit.

Visible mode retains the recorded end workflows; both are required if this plan has an end time. Connection reads still require valid YouTube and Facebook authorization.

Validation uses isolated fixtures. No real live, OBS output or physical camera was started, stopped or moved during these checks. Supervise the first real takeover on the Windows PC.
