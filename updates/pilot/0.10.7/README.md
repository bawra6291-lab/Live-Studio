# Live Desk 0.10.7 pilot update

Replaces the previous Social Media interface with the supplied DARSHANFLOW Pure Emerald Glass Studio. The supplied HTML, including its design, references and original posting behavior, is preserved byte-for-byte.

## Install

Finish active live streams, recordings and DARSHANFLOW dispatches, then pause automation. In Live Desk, open Updates, check for updates, and choose Download & install. Check connections after restarting. Open DARSHANFLOW from the left navigation.

## Connection and data behavior

DARSHANFLOW uses its own original API & Caption Setup and browser-local saved settings. It does not import Windows Credential Manager secrets. Previously saved Live Desk photos, drafts and connection settings are retained. The previous posting queue is paused at startup so hidden jobs do not continue posting.

Original document behavior is retained: photo assignments survive dashboard navigation and polling, but are not saved across a full reload. Complete the dispatch or export before closing or updating. The studio's original YouTube assist/webhook behavior and mobile layout are unchanged.

No real social-media posts, live streams, camera movement or Telegram messages were sent during validation.
