# Live Desk 0.10.5

Three independent daily photo columns: 7 portrait photos for Instagram/YouTube, 10 landscape photos for Instagram/YouTube, and 17 independently ordered Facebook photos. The selected order is preserved. Automatic matching controls are removed from this flow.

When live outputs and recording are idle, pause automation, open Updates and use Install an update file to select ISKCON-Live-Desk.zip. Saved settings are retained. After restart, open Social Media > Darshan batch.

Upload each column, arrange the numbered positions, add caption/times, and review the five drafts. Facebook and Instagram landscape use the existing approved API queue. YouTube photo posts and Instagram portrait remain manual ordered packages.

The package passed validation and is available through the opt-in pilot update feed after user-approved publication.
