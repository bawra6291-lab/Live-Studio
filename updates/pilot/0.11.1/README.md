# Live Desk 0.11.1 — Telegram restored

Install from Live Desk → Updates → Check for updates → Download & install while live/recording are idle and automation is paused.

## Connect Telegram

1. DARSHANFLOW → Connections → Telegram · channel connection.
2. Add your Telegram bot to your channel as an administrator with Post messages permission.
3. Enter its BotFather token and @channelusername or numeric -100… ID, then Save & verify Telegram.
4. If the previous studio saved settings in this browser, use Import previous Telegram settings. A blank token preserves the saved token. Credentials are kept in Windows Credential Manager.
5. Verify checks bot identity, channel identity and posting permission. It sends no test message.

## Publish

Upload the required real daily photos, then Publish → Telegram. Choose both albums (7 portrait followed by 10 landscape), or a single 7/10-photo album. Review the exact channel, photos and caption before Publish this telegram post.

The full caption appears on the first photo of each album. Telegram captions are limited to 1024 characters (emoji may count as two); nothing is silently shortened. Photos are fitted without cropping. ImgBB and Facebook/Instagram credentials are not required for Telegram.

Posting history keeps each album link and receipt. A partial, interrupted or uncertain send requires review and is not automatically repeated. Check the channel before creating a replacement draft.

Existing Facebook, Instagram, YouTube, WhatsApp and live settings remain in place. No real platform messages or posts were sent during validation. Test the first real Telegram post by reviewing your own channel and photos in the app.
